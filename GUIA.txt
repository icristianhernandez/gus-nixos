- Instala siguiendo las instrucciones normal de wsl nixos.

- Clona este repo

- Debes agregar el hardware-configuration que está en ( /etc/nixos/hardware-configuration.nix ) en ./system-modules/

- El otro documento que está al lado de hardware-configuration da igual.

- Debes cambiar los datos en ./lib/const.nix a los tuyos
^^^ Preferible pon en 'user' el mismo nombre que pusiste para el user durante la instalación, da menos detalles.

- Se rebuildea con el comando:
sudo nixos-rebuild switch --flake .#wsl

- Se actualizan las apps con:
(estando en esta carpeta)
nix flake update

- En scripts puse un bash para automatizar crear la ssh key y subirla a github
